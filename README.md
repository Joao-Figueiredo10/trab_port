# OCTO-SCAN 2026 — Detetor de Polvos

Aplicação escolar, satírica e autónoma em HTML, CSS e JavaScript. O radar é desenhado localmente; a análise de frases decorre no browser e não guarda nem envia o texto.

## Publicar na Vercel

Importa esta pasta como **Other / No Framework** e publica a raiz. Deixa os comandos de instalação e build vazios. Os ficheiros principais são `index.html`, `style.css` e `script.js`; o símbolo vectorial local está em `assets/octoscan-mark.svg`.

Com a Vercel CLI, também podes executar `npx vercel --prod` nesta pasta e seguir a configuração interactiva.

## Nota sobre Manus

A pasta `dist/` é uma cópia estática comprometida usada pela configuração de saída do projecto Manus. Não é necessária para publicar a raiz na Vercel.
